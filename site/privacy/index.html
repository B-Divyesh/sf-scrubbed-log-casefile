POLICY / 2026-08-28

Privacy.

Scrubbed Log Casefile is designed to keep incident data on your device.

CLI data

The CLI has no network client or telemetry. It reads the files you name and writes the archive you request. It reads archive passwords from an environment variable.

Browser demo

Demo text changes in your browser. It is not transmitted or saved. The service worker caches public pages for offline use.

Licenses

A license check contacts Sociobot at api.sociobot.in. The browser stores the token and last verdict in localStorage. Clear this site's storage to remove them.

Analytics and contact

This site loads no analytics, ads, third-party fonts, or tracking scripts. File questions in the public source repository.
