CLEAR LIMITS

Know what it does not do.

Rules cannot find every secret or identifier. Review the result before sharing. This is not a log host or cloud scrubber.

{
  "format": "scrubbed-log-casefile",
  "rule_hits": {
    "email": 14,
    "credential-assignment": 3
  },
  "token_scope": "this archive"
}

VERSION 0.1.2 / MIT

Build one local binary.

Run the bundled sample first, then pack your own incident files.

BUILD + DEMO
cargo install --git https://github.com/B-Divyesh/sf-scrubbed-log-casefile
casefile demo
export CASEFILE_PASSWORD='a-long-unique-passphrase'
casefile pack ./incident --output vendor.zip

Password stays out of arguments.
Read it from CASEFILE_PASSWORD or another variable.

Failure stays atomic.
Incomplete archives are removed. Existing output remains unless you pass --force.
