# Changelog

All notable changes follow Keep a Changelog. This project uses semantic
versioning and begins at `0.1.0`.

## [0.1.0] - 2026-08-28

### Added

- Offline `casefile pack` command with built-in and project-owned rules.
- Stable per-casefile placeholders and value-free provenance manifest.
- AES-256 encrypted ZIP output with atomic cleanup.
- Static documentation, local demo, license restore, privacy, and terms pages.
